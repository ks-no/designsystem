## Signal forms i Angular

Bind komponenten til skjemaet med `[formField]`. Verdien i skjemamodellen er alltid
primitiv: `string` ved enkeltvalg og `string[]` med `multiple`. Etiketten hentes fra
`ksd-suggestion-list-option`.

```ts
import { Component, signal } from '@angular/core'
import { FormField, form } from '@angular/forms/signals'
import { Field, Input, Label } from '@ks-digital/designsystem-angular/forms'
import {
  Suggestion,
  SuggestionList,
  SuggestionListEmpty,
  SuggestionListOption,
} from '@ks-digital/designsystem-angular/suggestion'

@Component({
  selector: 'app-velg-kommune',
  imports: [
    Field,
    FormField,
    Input,
    Label,
    Suggestion,
    SuggestionList,
    SuggestionListEmpty,
    SuggestionListOption,
  ],
  template: `
    <ksd-field>
      <ksd-label>Velg kommune</ksd-label>
      <ksd-suggestion [formField]="skjema.kommune">
        <input ksd-input />
        <button type="reset"></button>
        <ksd-suggestion-list>
          @for (kommune of kommuner; track kommune.value) {
            <ksd-suggestion-list-option [value]="kommune.value">
              {{ kommune.label }}
            </ksd-suggestion-list-option>
          }
          <ksd-suggestion-list-empty>Ingen treff</ksd-suggestion-list-empty>
        </ksd-suggestion-list>
      </ksd-suggestion>
    </ksd-field>
  `,
})
export class VelgKommune {
  kommuner = [
    { label: 'Bergen', value: '4601' },
    { label: 'Oslo', value: '0301' },
    { label: 'Trondheim', value: '5001' },
  ]
  model = signal({ kommune: '0301' })
  skjema = form(this.model)
}
```

## Kontrollert bruk i Angular

- Bruk `selected` for å styre valget utenfra. Den godtar både `{ label, value }`
  og rene verdier.
- `selectedChange` sender alltid ut `{ label, value }`, eller en liste med
  `multiple`.
- Bruk `selected` eller `formField`, ikke begge på samme komponent.
- Med `filter` kan du sende inn din egen filterfunksjon. Henter du forslag selv,
  for eksempel fra et API, slår du av filtreringen med `[filter]="false"`.
