# React

React-pakken er en 1-til-1-implementering av komponentene til Designsystemet. Under
Komponenter finner du React-kode for hver komponent. Retningslinjene for
komponentene finner du på [designsystemet.no](https://designsystemet.no/no/components).

## Installasjon

```bash
pnpm add @ks-digital/designsystem-react
```

## Bruk

1. Hvis du ikke allerede har gjort det, sett opp et [tema](/docs/design-tokens-temaer--docs) fra `@ks-digital/designsystem-themes`-pakken.

2. Importer og bruk komponentene du trenger:

```tsx
import { Button } from '@ks-digital/designsystem-react'

function MyComponent() {
  return <Button data-size="lg">My Button</Button>
}
```
