# Temaer

Løsningene som KS Digital utvikler, har ulik visuell identitet. Designsystemet gir oss en struktur for å bygge og vedlikeholde disse. Temaene er basert på design tokens – en W3C-standard som fungerer som felles kilde for både Figma og generert CSS.

Temaene distribueres som en sentral npm-pakke, slik at teamene raskt kan komme i gang – både i Figma og i kode.

Når du navigerer gjennom de ulike komponentene, kan du forhåndsvise dem i de ulike temaene og i lys og mørk modus via verktøylinjen øverst på siden.

## Tilgjengelige temaer

- **KS Digital**
- **KS Digital v2**
- **Ledsagerbevis**
- **Min Kommune**
- **Tilskudd**

## Om temaene

Ved å bruke et tema fra Designsystemet får du en generert fargeskala som er satt opp for å fungere med lys og mørk modus. Bruk bare farger som er definert i temaet – andre farger kan gjøre identiteten utydelig og bryte støtten for lys og mørk modus.

CSS-pakken inneholder også eventuelle stiler for egne komponenter. Disse bruker prefikset `ksd-` i stedet for `ds-`.

## Bruk

Installer temapakken:

```bash
pnpm add @ks-digital/designsystem-themes
```

### Last inn skrifttypen

Alle temaene bruker skrifttypen Inter, og den må lastes inn av applikasjonen din. Legg til denne i `index.html`:

```html
<link
  rel="stylesheet"
  href="https://static.fiks.ks.no/fonts/inter/4.1/inter.css"
  integrity="sha384-OcHzc/By/OPw9uJREawUCjP2inbOGKtKb4A/I2iXxmknUfog2H8Adx71tWVZRscD"
  crossorigin="anonymous"
/>
```

Importer basisstilene og temaet du vil bruke, i CSS- eller JavaScript/TypeScript-filene dine.

### CSS

Hvis bundleren din (for eksempel Vite) er satt opp til å løse npm-pakker i CSS-importer:

```css
@import url('@ks-digital/designsystem-themes/base.css');
@import url('@ks-digital/designsystem-themes/ksdigital.css');
```

#### Tailwind

Alle temaene kan integreres med Tailwind. Importer `[tema].tailwind.css`, som kobler Tailwind-klasser til Designsystemets tokens (eksperimentelt).

> Den første linjen styrer prioritetsrekkefølgen for CSS-layers: layers som er deklarert senere, vinner. Den anbefalte rekkefølgen plasserer `ds` og `ksd` over Tailwind, slik at Designsystemets stiler går foran. Trenger du at Tailwind-utilities overstyrer komponentstilene, kan du flytte `utilities` etter `ksd`. Det kan likevel gi problemer når pakkene oppdateres senere.

```css
@layer theme, base, utilities, ds, ksd;

@import url('@ks-digital/designsystem-themes/base.css');
@import url('@ks-digital/designsystem-themes/ksdigital.css');

@import 'tailwindcss/theme.css' layer(theme);
@import 'tailwindcss/preflight.css' layer(base);
@import 'tailwindcss/utilities.css' layer(utilities);
@import '@ks-digital/designsystem-themes/ksdigital.tailwind.css' layer(theme);
```

### JavaScript / TypeScript

Importer stilene direkte i applikasjonen din. Bruker du React, se README-en i React-pakken.

```javascript
import '@ks-digital/designsystem-themes/base.css'
import '@ks-digital/designsystem-themes/ksdigital.css'
```
