# Web-pakken

## Anbefalt bruk

Denne pakken utvider Designsystemet sin web-pakke. Den gir deg to ting i én import:

1. **Alt fra Designsystemet**, uendret og i sin helhet - web components og oppførsel som `data-tooltip` og `popover`.
2. **KS Digital sine egne komponenter og mønstre**.

Du skal derfor kun installere og importere vår pakke - ikke Designsystemet sin i tillegg.

```bash
pnpm add @ks-digital/designsystem-web @ks-digital/designsystem-themes
```

Importer pakken én gang, så tidlig som mulig i applikasjonen:

```javascript
import '@ks-digital/designsystem-web'
```

### Ikke importer Designsystemet i tillegg

`@digdir/designsystemet-web` er bygget inn i pakken vår.
