# Tabs

<OfficialDocsLink href="https://designsystemet.no/no/components/docs/tabs/overview" />

`Tabs` lar brukerne navigere mellom relaterte deler av innholdet, der én del vises om gangen. Dette er en effektiv måte å organisere og presentere relatert innhold på samme side.

## Bruk

```ts
import {
  Tabs,
  TabsList,
  TabsTab,
  TabsPanel,
} from '@ks-digital/designsystem-angular'

@Component({
  imports: [Tabs, TabsList, TabsTab, TabsPanel],
  template: `
    <ksd-tabs>
      <ksd-tabs-list>
        <button ksd-button ksd-tabs-tab value="value1">Tab 1</button>
        <button ksd-tabs-tab value="value2">Tab 2</button>
        <button ksd-tabs-tab value="value3">Tab 3</button>
      </ksd-tabs-list>
      <ksd-tabs-panel value="value1">content 1</ksd-tabs-panel>
      <ksd-tabs-panel value="value2">content 2</ksd-tabs-panel>
      <ksd-tabs-panel value="value3">content 3</ksd-tabs-panel>
    </ksd-tabs>
  `,
})
export class App {}
```
